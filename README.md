# Gerenciador de Orçamentos - Frontend

Aplicação frontend desenvolvida com **Next.js** para gerenciamento de orçamentos, itens e medições.

---

## 🚀 Tecnologias Utilizadas

- Next.js
- TypeScript
- Redux Toolkit
- Axios

---

## 📦 Instalação do Projeto

### 1. Clonar repositório

```bash
git clone <url-do-repositorio>

```
### 2. Instalar dependencias

```bash
npm install
```

### 3. Executar projeto

```bash
npm run dev
```
